📊 How The Permanent Database Works

┌─────────────────────────────────────────────────────────┐
│                    PERMANENT DATABASE                    │
│  ┌──────────────────────────────────────────────────┐  │
│  │  window.INTEGRITY_PASTE_DATABASE = {             │  │
│  │    sessionId: "abc123",                          │  │
│  │    pastes: [                                     │  │
│  │      { id: "p1", text: "ChatGPT response..." },  │  │

│  └──────────────────────────────────────────────────┘  │
│                           ↓                              │
│                    NEVER DELETED!                        │

                           ↓
                  When "Analyze" clicked
                           ↓
┌─────────────────────────────────────────────────────────┐
│              TEXT MATCHING ALGORITHM                     │
│                                                          │
│  for each paste in DATABASE:                            │
│    if paste.text in CURRENT_EDITOR_TEXT:                │
│       → Count as "still present" ❌ (bad)               │
│    else:                                                 │
│       → Count as "removed" ✅ (good)                    │
│                                                          │
│  Trust Score = (Typed + Removed) / Total × 100          │
└─────────────────────────────────────────────────────────┘
💡 Key Insight: The system tracks ALL paste events permanently. Trust score improves when pasted content is deleted/modified, proving the user is actively working on the content rather than just copying.

🧪 Test Scenario - Prove It Works!

1 Open UMO Editor

Click the button below to open the editor with integrity tracking:

🚀 Launch UMO Editor

2 Paste External Content

Copy this text and paste it into the editor:

The mitochondria is the powerhouse of the cell. It generates ATP through cellular respiration. This organelle has its own DNA and can replicate independently.

After pasting, open console (F12) and look for:

✅✅✅ PASTE PERMANENTLY STORED IN DATABASE! Total pastes in database: 1
3 Click "Analyze Integrity Now"

You should see in console:

✅ PASTE STILL IN DOC: The mitochondria is the powerhouse... 📊 TRUST SCORE: 0% (all content is pasted)
4 DELETE the Pasted Content

Select all the pasted text and delete it. Type your own content instead:

This is my own original content that I typed myself.
5 Click "Analyze Integrity Now" Again

Now you should see:

📊 PERMANENT database has: 1 historical pastes ❌ PASTE REMOVED FROM DOC: The mitochondria is the powerhouse... 📊 TRUST SCORE: 100% (pasted content was removed!)
✅ Success! Even though you pasted before, the system recognizes you removed it and now have original content!
6 Paste Multiple Times

Try pasting 3 different texts, then delete 2 of them. The system will track:

  • Total historical pastes: 3
  • Pastes still in document: 1
  • Pastes removed: 2
  • Trust score will reflect only the remaining paste!
