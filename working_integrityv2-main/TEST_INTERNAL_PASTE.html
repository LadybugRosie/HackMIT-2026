🔒 Internal vs External Paste Detection

The system now differentiates between your own content (internal) and external content!

✅ NEW FEATURES:

  • Internal Paste Detection: When you copy/cut YOUR OWN typed content and paste it back
  • External Paste Detection: When you paste from ChatGPT, websites, or other sources
  • Smart Trust Scoring: Internal pastes DON'T reduce trust score (it's your own work!)
  • Persistent Scores: Scores stay visible until you click "Analyze" again

📊 How The System Differentiates

Action Detection Method Classification Trust Score Impact
Type "Hello World" Tracked via keydown events TYPED No impact (100%)
Copy "Hello World" from editor Copy event captured, stored in buffer — —
Paste "Hello World" back Matches copy buffer → Internal INTERNAL No impact (your work)
Paste from ChatGPT Not in copy buffer → External EXTERNAL Reduces trust score

🎯 The Algorithm

// When paste event occurs: function handlePaste(pastedText) { // Check 1: Is it in our copy buffer? (recently copied from editor) if (copyBuffer.contains(pastedText)) { → INTERNAL PASTE (user's own work) } // Check 2: Does it match previously typed content? else if (typedHistory.contains(pastedText)) { → INTERNAL PASTE (user typed this before) } // Check 3: 70%+ word overlap with typed content? else if (wordOverlap(pastedText, typedHistory) > 0.7) { → INTERNAL PASTE (mostly user's words) } else { → EXTERNAL PASTE (from outside source) } } // Trust Score Calculation: Trust Score = (Typed + Internal) / Total × 100 // Internal pastes DON'T hurt the score!
